# Data Structures and Algorithms

This repository contains my solutions to various Data Structures and Algorithms (DSA) problems. The focus is on clean, readable code accompanied by detailed explanations and visual walkthroughs to make the underlying logic easy to grasp.

## Structure

The problems are categorized by topic to facilitate structured learning:

- **[Arrays_and_Hashing](./Arrays_and_Hashing)**: Problems focusing on array manipulation, hash maps, and sets for optimal lookups and counting.
- **[Two_Pointers](./Two_Pointers)**: Problems solved using two indices traversing the data structure simultaneously to reduce time complexity.
- **[SlidingWindow](./SlidingWindow)**: Problems involving a subset of elements (a "window") that shifts over an array or string.
- **[Strings](./Strings)**: Problems dealing with string parsing, character manipulation, and text algorithms.
- **[Heaps](./Heaps)**: Problems utilizing priority queues for efficiently maintaining running maximums or minimums.
- **[Greedy](./Greedy)**: Problems where making locally optimal choices at each step leads to a globally optimal solution.

## Solution Format

Each file is designed to be self-contained, explaining both the "why" and the "how". You will typically find:
1. **Problem Statement**: A clear summary of the core objective.
2. **Approach**: A high-level explanation of the chosen algorithm and why it is more optimal than a brute-force approach.
3. **Visual Walkthrough**: A step-by-step trace of how the algorithm processes a sample input, showing the state of variables, arrays, or pointers at key moments.
4. **Complexity Analysis**: Time and Space complexities (Big-O notation).
5. **Code Implementation**: The executable code for the solution.
